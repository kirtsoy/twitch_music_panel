# 🎵 420 Mixtape (Vol. 1) - Twitch Music Panel

Автономный встраиваемый веб-плеер официального микстейпа **«420 mixtape (vol. 1)»** артиста **KIRTSOY**.

Создан специально для Twitch-канала, OBS Browser Source и персонального веб-сайта.

---

## ⚡ Особенности
* **100% автономный звук**: Не требует Spotify Premium, не зависит от YouTube API, не имеет лимитов по квотам и времени.
* **Полный альбом (24 трека)**: Все оригинальные композиции в высоком качестве от первого до последнего трека.
* **Фирменный дизайн**: Неоновый дым, крутящийся винил, анимация живого эквалайзера (Web Audio API Frequency Visualizer).
* **Управление**: Play/Pause (Space), Next, Previous, Shuffle, Repeat, ползунок таймлайна (Seek Bar), регулятор громкости.
* **Вкладка треклиста**: Интерактивный список всех 24 треков с переключением в один клик.

---

## 🚀 Быстрый запуск на ПК
1. Запустите двойным кликом:
   ```cmd
   start_panel.bat
   ```
2. Плеер автоматически откроется в браузере по адресу:
   **`http://localhost:8505`**

## 📺 Варианты интеграции в Twitch

### 1. Как кликабельная панель под стримом (Twitch Channel Panel)
1. В настройках канала Twitch перейдите в **Редактировать панели**.
2. Добавьте панель с картинкой обложки (`assets/cover.png` или `assets/cover.webp`).
3. В поле **«Ссылка изображения»** вставьте ссылку на ваш развернутый плеер (например, на GitHub Pages).
4. Любой зритель кликает по панели — и у него открывается полнофункциональный неоновый плеер с возможностью слушать альбом без всяких подписок!

### 2. Как оверлей в OBS (OBS Browser Source)
1. В OBS добавьте источник **Браузер (Browser Source)**.
2. URL: `http://localhost:8505`
3. Ширина: `340`, Высота: `580`
4. Поставьте галочку **«Управлять звуком через OBS»** (если хотите транслировать звук прямо через виртуальный кабель браузера).

### 3. Публичный доступ для зрителей 24/7 (Бесплатно)
Чтобы зрители могли слушать альбом даже когда ваш ПК выключен:
* Загрузите содержимое этой папки в репозиторий **GitHub Pages** или **Cloudflare Pages** (бесплатный хостинг статики).
* Всё аудио, стили и скрипты полностью статичны — разворачиваются за 1 минуту!
